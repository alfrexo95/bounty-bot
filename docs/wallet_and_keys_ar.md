# المحفظة والمفاتيح (Wallet and Keys)

تعتبر المحفظة الرقمية هي البوابة الأساسية للتفاعل مع شبكة Janzeer. لفهم كيفية عملها، يجب التمييز بين المفاتيح العامة والخاصة.

## 1. المفاتيح الخاصة (Private Keys)
المفتاح الخاص هو بمثابة كلمة المرور السرية التي تمنحك السيطرة الكاملة على أصولك.
- **تحذير:** لا تشارك مفتاحك الخاص مع أي شخص أبداً. إذا فقدت مفتاحك الخاص، ستفقد الوصول إلى محفظتك نهائياً.

## 2. المفاتيح العامة (Public Keys)
المفتاح العام هو العنوان الذي تشاركه مع الآخرين لاستقبال العملات أو البيانات. يمكن اعتباره بمثابة رقم الحساب البنكي.

## 3. إنشاء محفظة باستخدام Janzeer SDK
يمكنك إنشاء محفظة جديدة برمجياً باستخدام مكتبة Janzeer Python:

```python
from janzeer import Wallet

# إنشاء محفظة جديدة
wallet = Wallet.create()

print(f"العنوان العام: {wallet.public_address}")
print(f"المفتاح الخاص: {wallet.private_key}")
```

## 4. أفضل الممارسات
- قم دائماً بعمل نسخة احتياطية من مفاتيحك في مكان آمن (Offline).
- استخدم محافظ الأجهزة (Hardware Wallets) للمبالغ الكبيرة.
- تأكد من أن بيئة التطوير الخاصة بك لا تقوم بتسجيل (Log) المفاتيح الخاصة في ملفات نصية غير مشفرة.
